# FAQ-бот «ИИ-консультант компании»

## Цель
Telegram-бот, который отвечает на вопросы клиентов компании по её базе знаний.
Клиент получает ответ сразу, в любое время, а менеджеры не тратят время на одни и те же вопросы
(доставка, оплата, гарантия, часы работы).

Главный принцип — честность: бот отвечает только тем, что есть в базе знаний.
Если ответа нет, он прямо говорит об этом и предлагает связаться с менеджером.
Никаких выдуманных цен, сроков и обещаний от имени компании.

## Пользователи
- **Клиенты компании** — задают вопросы боту в Telegram.
- **Владелец бота** — пополняет базу знаний, добавляя файлы в папку `knowledge/`.

## Как это работает
1. Клиент пишет вопрос боту в Telegram.
2. Бот загружает базу знаний — все `.txt` и `.pdf` файлы из папки `knowledge/`.
3. Бот отправляет нейросети весь текст базы знаний вместе с вопросом и инструкцией
   «отвечай только по этому тексту, если ответа нет — так и скажи».
4. Бот возвращает клиенту ответ нейросети.

```
Клиент → Telegram → бот → [база знаний + вопрос] → нейросеть → ответ → клиент
```

## Архитектурные решения
- **Без векторной базы данных.** Пока база знаний небольшая, её текст целиком передаётся
  нейросети с каждым вопросом. Это проще и надёжнее. Пересмотреть, когда база перестанет
  помещаться в запрос к нейросети.
- **База знаний — обычные файлы.** Чтобы обновить ответы, достаточно заменить файл
  в `knowledge/`, код менять не нужно. Бот файлы только читает и никогда не изменяет.
- **Ключи отдельно от кода.** Токен бота и ключ API нейросети хранятся только в `.env`.

## Границы проекта (что бот НЕ делает)
- Не принимает заказы и оплату.
- Не запоминает историю разговоров с клиентом.
- Не переписывается с клиентом от имени менеджера — только предлагает с ним связаться.

## Статус
Учебный проект. Сейчас — подготовка: описание и тестовая база знаний `knowledge/faq.txt`
для вымышленной компании. Кода пока нет.
